# 操作手册

本手册面向日常使用者与管理员，介绍 baobaobaivault 上线后如何注册、创作、管理、配置与排错。

如果你还没有完成部署，请先阅读 [部署说明](./deploy)。

---

## 1. 登录与注册

首次访问站点时，点击右上角**登录/注册**进入认证页面。

### 1.1 管理员首次登录

部署完成后，系统已经通过 `scripts/create-admin.sh` 创建了初始超级管理员。首次登录时：

1. 使用脚本输出的随机密码登录。
2. 系统会强制要求修改密码。
3. 修改完成后即可进入系统。

::: tip
超级管理员的邮箱来自 `backend/config/config.yaml` 中的 `server.admin_email`。如果这个邮箱尚未注册过，第一次登录会自动绑定并创建管理员账号。
:::

### 1.2 普通用户注册

默认注册流程：

1. 输入邮箱、用户名、昵称、密码。
2. 点击注册，成功后自动登录。

如果管理员在**系统管理 → 认证设置**中开启了**邮箱验证码注册**，则需要：

1. 填写注册信息。
2. 点击**发送验证码**。
3. 查收邮件并输入验证码。
4. 完成注册。

### 1.3 找回密码

在登录页点击**忘记密码**，输入邮箱后系统会发送重置链接或验证码，按提示完成重置即可。

## 2. 角色与权限

系统内置三种角色：

| 角色 | 说明 | 典型权限 |
| --- | --- | --- |
| `viewer` | 浏览者 | 浏览公开卡片、收藏、下载 |
| `creator` | 创作者 | 创建/编辑自己的卡片、生成访问码、查看投稿状态 |
| `manager` | 管理员 | 系统配置、用户管理、审核投稿、管理存储与角色 |

::: tip
管理员可以在**系统管理 → 角色管理**中创建自定义角色，并分配不同菜单与接口权限。
:::

---

## 3. 创作者中心

登录后，具有 `creator` 或以上角色的用户可在顶部菜单进入**创作中心**。

### 3.1 创建卡片

1. 点击**新建卡片**。
2. 填写基本信息：
   - **标题**：卡片名称。
   - **描述**：卡片简介，支持 Markdown 或纯文本。
   - **标签**：用逗号分隔，便于检索。
3. 设置可见性与访问模式：
   - **公开 / 私有**：决定是否出现在发现广场。
   - **免费 / 付费**：决定是否需要访问码或付费解锁（当前版本付费能力依赖访问码实现）。
4. 上传封面：
   - 点击封面区域，选择本地图片。
   - 上传成功后可在卡片详情页预览。
5. 上传附件：
   - 支持上传多个附件，每个附件占用一个固定 slot。
   - 上传完成后可修改附件名称、排序。
6. 点击**保存**或**投稿审核**。

::: tip
草稿状态仅自己可见；投稿后进入 `pending` 状态，等待管理员审核。
:::

### 3.2 编辑与删除卡片

在创作中心列表中：

- 点击卡片标题进入编辑页。
- 可修改标题、描述、标签、可见性、封面与附件。
- 点击**删除**可移除卡片（历史下载记录通常保留）。

### 3.3 管理访问码

对私有或付费卡片，创作者可生成访问码：

1. 进入卡片详情或访问码管理页。
2. 点击**生成访问码**。
3. 设置：
   - 过期时间（可选）。
   - 使用次数限制（0 表示不限制）。
4. 复制访问码并分发给目标用户。

用户在公开卡片页输入访问码后即可解锁内容。

## 4. 发现广场

发现广场是面向所有访客的公开页面，展示已通过审核且可见性为**公开**的卡片。

访客可以：

- 按分类筛选：系统主题、微信主题、桌面组件、角色设定、世界书、应用等。
- 搜索卡片标题与标签。
- 点击卡片进入详情页，预览封面与附件。
- 登录后收藏感兴趣的卡片。

::: tip
发现页显示哪些分类，由管理员在**系统管理 → 分类设置**中开启或关闭。
:::

---

## 5. 个人中心

登录后点击头像进入个人中心，可管理：

- **个人资料**：昵称、头像、简介、联系方式。
- **我的收藏**：查看已收藏的公开卡片。
- **我的访问码**：查看自己获得或生成的访问码。
- **修改密码**：出于安全考虑，建议定期更换。
- **注销账号**：删除自己的账号与数据（不可逆）。

## 6. 管理员后台

具有 `manager` 角色的用户可在顶部菜单进入**系统管理**，包含以下模块。

### 6.1 总览

系统管理首页提供快捷入口与核心指标概览，例如：

- 用户数量
- 卡片数量
- 待审核投稿
- 存储模式

### 6.2 站点品牌

用于定制站点对外形象：

| 配置项 | 说明 |
| --- | --- |
| 站点名称 | 浏览器标题与首页主标题 |
| 站点短名称 | 紧凑场景下的名称 |
| 站点描述 | SEO 与首页副标题 |
| Logo | 上传站点 Logo 图片 |
| 页脚文案 | 站点底部版权或说明 |
| 默认创作者名称 | 未设置昵称时的默认展示 |

修改后刷新页面即可生效（Next.js 会在后台自动重新验证相关缓存）。

### 6.3 认证设置

- **邮箱验证码注册**：开启后新用户注册需验证邮箱。
- **验证码有效期**：默认 600 秒。
- **重发间隔**：默认 60 秒。
- **最大验证次数**：防止暴力尝试。
- **SMTP 测试**：配置邮箱后，可点击**测试发信**验证连通性。

邮箱 SMTP 配置位于 `backend/config/config.yaml` 的 `email` 段落。详情参考 [邮箱验证码部署说明](../../backend/config/SHARE_AUTH_EMAIL_DEPLOY_ZH.md)。

### 6.4 分类设置

管理员可以控制发现广场展示哪些内容分类：

- 系统主题
- 微信主题
- 桌面组件
- 角色设定
- 世界书
- 应用

关闭某个分类后，该分类的卡片不再出现在发现广场筛选器中，但已创建的卡片数据仍然保留。

### 6.5 角色管理

1. 进入**系统管理 → 角色管理**。
2. 点击**新增角色**，输入角色名称与标识。
3. 勾选该角色拥有的权限集合。
4. 保存后可在**用户管理**中将角色分配给用户。

### 6.6 用户管理

管理员可：

- 查看所有注册用户。
- 修改用户角色（viewer / creator / manager 或自定义角色）。
- 锁定/删除用户。
- 重置用户密码。
- 查看用户创建的卡片与审核记录。

### 6.7 投稿审核

创作者投稿后，卡片进入待审核队列：

1. 管理员进入**系统管理 → 审核管理**。
2. 查看待审核卡片详情。
3. 选择：
   - **通过**：卡片变为公开状态，进入发现广场。
   - **驳回**：填写原因，创作者可修改后重新投稿。
   - **下架**：已通过卡片可被强制下架，恢复为私有或草稿。

### 6.8 媒体存储

控制卡片封面与附件的存储位置：

| 配置项 | 说明 |
| --- | --- |
| 存储模式 | `local` 本地存储 或 `object_storage` 对象存储 |
| 本地回退 | 开启后，老本地文件仍可读取 |
| 封面命名空间 | 新封面上传到的命名空间 |
| 附件命名空间 | 新附件上传到的命名空间 |

切换步骤建议：

1. 先在**存储配置**与**命名空间**中创建好对象存储资源。
2. 在**对象管理**中手动上传测试文件，确认链路正常。
3. 再将媒体存储切到 `object_storage`。
4. 上传新卡片验证封面与附件。
5. 观察一段时间后，再决定是否迁移历史文件。

详细步骤参考 [存储到媒体上传操作手册](./storage-workflow)。

### 6.9 存储配置

用于配置对象存储连接信息：

- Provider：阿里云 OSS、AWS S3、MinIO、腾讯云 COS 等。
- Endpoint、Region、Bucket。
- Access Key / Secret Key。
- Path Style（部分私有 MinIO 需要开启）。
- 默认配置标记。

::: warning
Access Key 与 Secret Key 会被后端加密存储。修改时留空表示保持原值。
:::

### 6.10 命名空间

命名空间用于逻辑隔离对象存储中的文件：

- 绑定一个存储配置。
- 设置路径前缀，例如 `share/covers`、`share/assets`。
- 可配置容量配额、文件数限制、单文件大小限制。

推荐至少创建两个命名空间：

1. **封面命名空间**：用于卡片封面。
2. **附件命名空间**：用于卡片附件。

### 6.11 对象管理

在对象存储模式下，管理员可直接上传、下载、删除、版本回滚对象：

1. 选择命名空间。
2. 点击**上传对象**。
3. 文件上传成功后出现在对象列表。
4. 支持**预签名下载**、**版本查看**、**回滚到指定版本**。

### 6.12 审计日志

系统会记录关键管理操作，例如：

- 用户角色变更
- 站点品牌修改
- 媒体存储模式切换
- 存储配置增删改

管理员可在**系统管理 → 审计日志**中按时间、用户、操作类型筛选。

## 7. 常见问题

### 7.1 页面能打开但无法登录

- 检查是否使用 HTTPS 访问。
- 后端在 `release` 模式下会设置 `Secure` Cookie，HTTP 环境下登录会失败。

### 7.2 前端能打开但 API 返回 502/504

- 查看 `docker compose ps` 确认 `backend` 是否健康。
- 查看 `docker compose logs -f backend` 排查数据库/Redis 连接问题。

### 7.3 上传文件后重建容器丢失

- 检查 `docker-compose.yml` 是否正确挂载了 `./backend/storage:/app/storage`。
- 如果使用 OSS 模式，检查命名空间与存储配置是否正确。

### 7.4 发现广场不显示某些分类

- 进入**系统管理 → 分类设置**，确认对应分类已开启。

### 7.5 投稿后用户看不到自己的卡片

- 卡片投稿后处于 `pending` 审核状态，管理员通过审核后才会公开。
- 或者被管理员下架/驳回。

### 7.6 访问码失效

- 检查访问码是否已过期。
- 检查使用次数是否已达上限。
- 检查卡片是否被创作者删除或下架。

---

## 8. 推荐日常运维

- 定期备份 `data/postgres` 与 `backend/storage`。
- 固定镜像版本标签，避免自动拉取导致意外升级。
- 开启邮箱验证前先测试 SMTP 连通性。
- 切换 OSS 前保留本地回退，避免历史文件无法访问。
- 不要随意重置 `jwt.secret` 或 `security.field_encryption_key`，否则可能导致已加密凭证失效。
